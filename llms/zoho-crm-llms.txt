# Zoho CRM

> Zoho CRM is Zoho Corporation's sales and customer-relationship platform. Its REST API (current major version v8) is documented and, since the v8 release, published as first-party OpenAPI 3.1.0 — 105 specification files covering 405 operations at https://github.com/zoho/crm-oas. Authentication is OAuth 2.0 authorization-code against accounts.zoho.com, with 458 distinct scopes. The API host is region-templated: https://zohoapis.{dc}/crm/{version} where dc is one of com, eu, in, cn, au.

Generated by API Evangelist on 2026-08-13 from this provider profile. Zoho serves no llms.txt of its own (https://www.zoho.com/llms.txt and https://www.zoho.com/crm/llms.txt both return 404).

## Before your first call

- Authorization header is `Authorization: Zoho-oauthtoken {access_token}` — NOT `Bearer`. This is the most common first-call failure.
- Access tokens live one hour; refresh tokens live until revoked.
- Resolve your org's data centre first. The same account is not reachable on every host.
- Module names are runtime data. Call `getModules` before constructing a record body, and substitute the real module API name into scopes: `ZohoCRM.modules.Leads.READ`, not `ZohoCRM.modules.{module_API_name}.READ`.
- A `200` does not mean a batch succeeded. Batch writes return `207 Multi-Status` with a per-record `code`/`status` inside `data[]`.
- There is no idempotency key. Retrying `createRecords` creates duplicates — use `upsertRecords` with `duplicate_check_fields` for any retryable write.

## APIs

- [Zoho CRM REST API v8](https://www.zoho.com/crm/developer/docs/api/v8/): 105 OpenAPI files, 405 operations, base https://zohoapis.{dc}/crm/{version}
- [Records](https://www.zoho.com/crm/developer/docs/api/v8/get-records.html): getRecords, getRecord, createRecords, updateRecord, updateRecords, deleteRecord, deleteRecords, upsertRecords, getDeletedRecords, cloneRecord
- [Modules metadata](https://www.zoho.com/crm/developer/docs/api/v8/): getModules — the discovery call every integration starts with
- [COQL](https://www.zoho.com/crm/developer/docs/api/v8/COQL-Overview.html): SQL-like query over CRM records
- [Bulk Read / Bulk Write](https://www.zoho.com/crm/developer/docs/api/v8/): asynchronous job-based import and export
- [Composite Requests](https://www.zoho.com/crm/developer/docs/api/v8/): batch several operations into one call
- [Notifications (webhooks)](https://www.zoho.com/crm/developer/docs/api/v2/notifications/): register a notify_url and receive create/edit/delete callbacks
